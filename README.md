# Python Machine Learning Lab Work

A collection of Python laboratory exercises demonstrating the fundamentals of **NumPy**, **Pandas**, and **Matplotlib** for data analysis and visualization. This repository was created as part of Machine Learning laboratory coursework and serves as a practical reference for beginners learning Python for Data Science and Machine Learning.

---

## Features

- NumPy array operations
- Matrix creation and manipulation
- Random number generation
- Statistical computations
- Pandas Series and DataFrames
- Reading CSV and Excel files
- Data filtering and selection
- Basic data preprocessing
- Data visualization using Matplotlib
- Line plots, bar charts, scatter plots, and histograms
- Hands-on Machine Learning lab exercises

---

## Technologies Used

- Python 3.x
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib

---

## Concepts Covered

- Python Programming Fundamentals
- Numerical Computing with NumPy

## Installation

### Clone the Repository

```bash
git clone https://github.com/Kushagra-des/ML_Lab_Work.git
```

### Navigate to the Project Directory

```bash
cd ML_Lab_Work
```

### Install Required Libraries

```bash
pip install numpy pandas matplotlib notebook
```

---

## How to Run

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open any notebook (`.ipynb`) and run the cells sequentially.
